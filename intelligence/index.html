04 / DATA CONTRACT

What the model knows

Clear separation between verified game data, inferred player status and unavailable information.

Verified rolling team data

Pregame ORtg, DRtg, pace, eFG, three-point rate, turnovers, offensive/defensive rebounding, free-throw rate and opponent tendencies over last 5, last 10, season and prior season.

Inferred rotations

Expected minutes, usage and an impact proxy use only prior appearances. A missed appearance can be injury, rest, coaching choice or roster movement—it is never presented as a confirmed diagnosis.

Independent simulation

Possessions independently play turnovers, free throws, 2s, 3s, misses, offensive rebounds and overtime. Elo does not set the independent model's score.

Rolling-origin selection

Each season's window, shrinkage and blend weight are selected only from earlier seasons. The 71-game 2026–27 check is separately labelled small-sample corroboration.
